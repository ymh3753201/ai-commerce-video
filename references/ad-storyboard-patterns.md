# Ad Storyboard Patterns

Use these patterns to produce a complete first proposal quickly.

## Pattern A: Product Hero Reveal

Best for: beauty, food, gadgets, supplements, packaging-heavy products.

Default 15s:

- 0-2s: strong hook, product enters frame;
- 3-6s: close-up texture or key visual proof;
- 7-10s: product in use or before/after visual;
- 11-13s: benefit stack, price or offer;
- 14-15s: hero frame and CTA.

## Pattern B: UGC Digital Model Review

Best for: consumer goods, home products, small gadgets, daily-use products.

Default speaker mode: visible model/digital-human spoken selling. The presenter talks to camera; do not use off-screen voiceover unless requested.

Default 15s:

- 0-2s: model directly addresses a pain point;
- 3-6s: model holds or uses product;
- 7-10s: quick proof or feature demonstration;
- 11-13s: emotional benefit;
- 14-15s: CTA and offer.

If no model image exists, generate a synthetic model reference. Do not imply it is a real customer unless the user provides permission and proof.

For inanimate products, the presenter or hands may move the product. The product must not move by itself or act alive.

## Pattern C: Problem-Solution Demo

Best for: tools, cleaning products, health products, software, household items.

Default 15s:

- 0-3s: show the problem visually;
- 4-8s: introduce product as solution;
- 9-12s: show measurable or visible improvement;
- 13-15s: CTA.

## Pattern D: Premium Minimal Ad

Best for: luxury, high-price items, gift products, skincare, electronics.

Default 15s:

- 0-3s: dark or clean studio hero shot;
- 4-8s: macro details, slow camera, material highlight;
- 9-12s: lifestyle context;
- 13-15s: tagline and offer.

## Pattern E: Feature Walkthrough

Best for: products with 3 clear selling points.

Default 15s:

- 0-2s: hook;
- 3-6s: feature 1;
- 7-10s: feature 2;
- 11-13s: feature 3;
- 14-15s: CTA.

## Copy Rules

- Default to presenter spoken copy, not detached narration.
- Keep voiceover short: about 2 to 2.5 Chinese characters per 0.1 second is often too dense; prefer fewer words and stronger rhythm.
- Put only the strongest claim on screen.
- Avoid unsupported medical, financial, and guaranteed-result claims.
- If the user provides a price, include it near the CTA, not in every shot.

# Proposal Template

Use this structure for the first confirmation proposal. Adapt wording to the product, but keep all sections.

For an ordinary one-product request, render the AI-recommended plan in full and the alternative as a short comparison card. Expand all A/B/C/D/E sections only when the user asks for multiple variants or campaign testing. The user should be able to reply `按 AI 推荐` without learning technical terms.

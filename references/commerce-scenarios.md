# Commerce Scenarios

Use this reference before drafting the first proposal and when setting `--commerce-scenario`. A scenario is the business situation; a creative variant is the ad expression. For example, `ugc_review` can be a scenario and a creative variant, while `pain_solution` can use `story_reversal` or `hybrid`.

## Scenario Table

| Scenario ID | Chinese label | Best platforms | Product fit | Typical structure | Image/reference needs | Risk control |
|---|---|---|---|---|---|---|
| `feature_demo` | 商品功能演示 | Amazon, Shopify, Douyin, TikTok | Tools, electronics, home goods, beauty devices, kitchen products | Need/problem -> feature demo -> close-up proof -> result -> CTA | Product hero, hand/use close-up, detail macro, final source frame | Only show real functions; avoid impossible motion or fake results. |
| `product_detail_page` | 商品详情页视频 | Amazon, Shopify, marketplaces | Products needing size/material/use proof | Hero -> material/size -> use case -> package/variant -> buying confidence | Clean hero, macro detail, size/scale reference, usage scene | Do not overuse story; keep product information clear. |
| `ugc_review` | UGC 买家测评 | Xiaohongshu, TikTok, Reels | Beauty, home, fashion, gadgets, lifestyle | Buyer-style hook -> real-feeling use -> proof detail -> honest comment -> CTA | Buyer/presenter, usage scene, product detail, caption-safe frame | Do not invent fake identity, medical result, or unsupported testimonial. |
| `unboxing` | 开箱体验 | Xiaohongshu, TikTok, Shopify | Gifts, electronics, cosmetics, toys, fashion | Package reveal -> first impression -> detail -> setup/use -> CTA | Packaging, hands, hero product, accessory/detail references | Keep packaging and included items accurate. |
| `before_after` | 前后对比 | Douyin, TikTok, Xiaohongshu, Meta | Cleaning, organization, beauty, fitness, home improvement | Before -> product use -> after -> proof/caveat -> CTA | Before scene, use scene, after scene, disclaimer-safe caption | Avoid guaranteed results and manipulated comparisons. |
| `comparison_test` | 竞品/方案对比 | Amazon, YouTube, TikTok, Shopify | Feature-led products where objective comparison helps | Neutral test setup -> side-by-side -> measurable advantage -> CTA | Side-by-side setup, test detail, result caption, product hero | Avoid competitor attacks, trademark misuse, or unsupported superiority claims. |
| `pain_solution` | 痛点解决方案 | Douyin, TikTok, Meta, YouTube | Broad conversion products | Pain point -> failed workaround -> product solution -> relief -> CTA | Pain scene, solution scene, product/presenter source, storyboard if multi-scene | Do not shame users or exaggerate pain. |
| `lifestyle_seed` | 生活方式种草 | Xiaohongshu, TikTok, Reels, premium Shopify | Fashion, home, decor, wellness, travel goods | Aspirational scene -> natural product presence -> benefit detail -> soft CTA | Lifestyle scene, product-in-scene, style reference, clean source frame | Product cannot disappear into mood shots; experience must stay plausible. |
| `premium_brand` | 高端品牌广告 | YouTube, Reels, Xiaohongshu, Shopify | Fashion, furniture, beauty, audio, design goods | Brand texture -> material/design detail -> restrained use -> concise value -> elegant CTA | Premium hero, material macro, brand scene, typography-safe frame | Avoid noisy stickers, cheap discount language, and unsupported luxury claims. |
| `live_shopping_teaser` | 直播间引流 | Douyin, TikTok Shop, Taobao-style live commerce | Discount, demo-heavy, seasonal products | Live reason -> hero product -> demo/offer preview -> time/action CTA | Presenter/live-room frame, product hero, offer caption, CTA-safe source | Offer and scarcity must be true. |
| `retargeting_offer` | 限时优惠 / 再营销广告 | Meta, TikTok, Douyin, email/site retargeting | Products with known browsing interest | Reminder -> objection answer -> offer/trust proof -> urgent CTA | Product hero, offer caption, trust proof, landing context | Avoid fake countdowns and fake discounts. |
| `new_launch` | 新品发布 | YouTube, TikTok, Xiaohongshu, Reels, Shopify | New SKUs and brand launches | Newness hook -> differentiator -> proof -> launch CTA | Launch hero, feature reveal, brand/product detail, CTA-safe frame | Do not claim first/best/new unless supported. |

## Choosing a Scenario

- If the user asks for a product listing or product detail page, choose `product_detail_page` or `feature_demo`.
- If the user asks for buyer review, seed content, or Xiaohongshu style, choose `ugc_review` or `lifestyle_seed`.
- If the user asks for premium, brand tone, or high-end visual quality, choose `premium_brand`.
- If the user asks for multiple versions for paid testing, create a creative matrix across scenario, hook, CTA, offer, and aspect ratio.
- If the user gives no scenario, infer from product category and platform, then state the assumption.

## Batch Creative Matrix

Professional e-commerce advertising usually tests more than one video. Use this matrix in the plan when the user asks for batch testing or when paid ads are implied:

| Axis | Examples |
|---|---|
| Hooks | pain-point hook, visual surprise, price/offer hook, social-proof hook, premium texture hook |
| CTA | shop now, learn more, add to cart, watch live, save and compare |
| Offer expression | discount, bundle, free shipping, limited quantity, launch price |
| Selling-point order | function first, material first, lifestyle first, proof first |
| Aspect ratio | `9:16`, `16:9`, `1:1` |
| Platform version | TikTok/Douyin, Xiaohongshu, Amazon, YouTube, Meta, Shopify |
| Creative variant | `commerce_direct`, `ugc_review`, `comparison_test`, `lifestyle_seed`, `premium_brand`, `feature_demo`, `unboxing`, `live_shopping_teaser`, `retargeting_offer` |

For batch plans, prepare a matrix first. Do not generate all videos until the user confirms which cells should move forward.

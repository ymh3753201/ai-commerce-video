# AI 电商带货视频 Skill

[English](README.md)

`ai-commerce-video` 是一个面向 Codex 的开源 Skill。普通用户只需要提供商品图片和简短需求，Codex 就可以通过多模态能力分析商品、平台、受众和卖点，设计带货广告方案，并在用户确认后执行图片准备、视频生成、拼接、字幕和质量验收。

## 核心特点

- 默认生成适合电商转化的 15 秒商品广告。
- 支持抖音、TikTok、小红书、Amazon、Meta、YouTube 和独立站等场景规划。
- 先分析商品并输出专业广告方案，不会收到素材后直接调用付费视频接口。
- 采用两次确认：
  1. 确认广告方案和图片计划；
  2. 确认实际生成并保存到本地的图片。
- 第二次确认后仍会先进行免费预检，最后才请求用户确认付费生成。
- 视频模型禁止直接生成字幕、价格、CTA、角标、水印等文字。
- 字幕只能在干净视频通过审核后，通过本地后期生成和烧录。
- 每个计划镜头只允许提交一次付费请求；接口状态不确定时继续查询原任务，不自动重复付费。

## 当前适配的视频模型

| 配置名称 | 接口适配层 | 实际模型 ID | 已适配能力 |
|---|---|---|---|
| `grok_video_15` | 第三方 `119337` | `grok-video-1.5` | 单张参考图生成视频、原生语音、口型同步、最长 15 秒；对应 `grok-imagine-video-1.5` 模型家族 |
| `grok_image_video` | 第三方 `119337` | `grok-image-video` | 文生视频或参考图视频；最多 7 张参考图；单图最长 15 秒，多参考图最长 10 秒 |
| `seedance2` | fal queue | `bytedance/seedance-2.0/reference-to-video` | 最多 9 张参考图、原生音频、最长 15 秒 |

重要说明：

- `119337` 是第三方网关，不是 xAI 官方接口。
- 第三方 Grok 配置不会读取 `XAI_API_KEY`，避免把官方密钥误发给第三方。
- xAI 官方 API 的地址、字段和轮询格式不同，不能只把第三方配置中的 URL 改为 `api.x.ai`。
- 模型名称相同不代表接口兼容。真正的适配对象是“接口地址、鉴权方式、请求字段、模型能力、时长、参考图限制、返回格式和轮询流程”的完整组合。

## 切换其他视频模型

如果需要切换 Kling、Veo、Runway、其他 Grok 网关或新版本 Seedance，必须根据新模型能力优化这个 Skill，不能只修改模型名称。

至少需要检查和适配：

1. 新建独立的模型配置，不覆盖已经验证的模型配置。
2. 配置创建任务、查询任务和获取结果的接口地址。
3. 配置专用 API Key 环境变量，禁止不同服务商混用密钥。
4. 配置文生视频、单图、多参考图、首尾帧、视频延长等输入能力。
5. 配置模型允许的时长、分辨率、画幅和参考图数量。
6. 确认模型是否真的支持原生语音、中文口播和口型同步。
7. 配置真实请求字段以及任务成功、失败、超时的返回格式。
8. 根据模型能力调整分段策略、参考图策略、提示词长度和连续性要求。
9. 增加离线请求测试、模拟提交/轮询测试、免费预检测试和密钥隔离测试。
10. 重新运行全部测试和开源发布审查。

## 安装

将仓库复制到 Codex Skill 目录：

```bash
rsync -a --delete --exclude '.git/' ./ ~/.codex/skills/ai-commerce-video/
```

然后在 Codex 中使用：

```text
$ai-commerce-video
```

用户可以直接提供：

- 一张或多张商品图；
- 希望发布的平台；
- 视频时长；
- 带货风格；
- 是否需要真人/数字人口播；
- 是否需要后期字幕。

信息不完整时，Codex 会以广告策划和电商视频导演的身份补充合理假设，并给出推荐方案。

## 标准制作流程

1. 分析商品图片、卖点、受众和平台。
2. 输出推荐广告方案和一个简短备选方案。
3. 用户确认方案。
4. Codex 使用内置生图工具生成视频使用的验收图。
5. 用户确认实际图片。
6. 运行免费配置检查、平台检查和请求预检。
7. 用户单独确认付费视频生成。
8. 视频任务只提交一次，并通过任务 ID 查询或恢复。
9. 多段视频按照完整语句边界拼接。
10. 审核商品一致性、文字污染、口播完整性和关键事实。
11. 如用户确认需要字幕，再进行本地字幕制作。
12. 只有 `delivery-manifest.json` 为 `status=pass` 才能称为正式交付。

## 私密配置

执行：

```bash
python3 scripts/setup_private_env.py
```

密钥会保存在：

```text
~/.codex/ai-commerce-video.env
```

真实 API Key 不得写入仓库、项目计划、请求日志、测试文件或 `.skill` 安装包。

## 当前限制

- 默认推荐 15 秒视频。
- 超过 15 秒会分段生成并拼接，但分段文件能够拼接不代表人物、声音、口型和动作一定无缝连续。
- 第三方模型网关的能力和价格可能变化，付费生成前必须重新预检。
- 平台规则属于制作规划参考，正式投放前需要复核平台最新政策。
- 合规说明不能代替法律意见。
